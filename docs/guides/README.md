# Guides

Short guides for people using Skelcrew. Each one takes a few minutes to read.

1. [Getting started](getting-started.md): install Skelcrew, set up a repository, and merge your first task.
2. [The screen](the-screen.md): the sidebar, opening an agent, and getting back.
3. [How a task goes](how-a-task-goes.md): from the lead's proposal to the merge.
4. [Needs you](needs-you.md): what lands in your inbox, and how to answer it.
5. [Running on a server](running-on-a-server.md): keep your agents working while your laptop sleeps.

`sc --help` lists every command and key. The full design is in [the spec](../spec.md).
