Run sc start or sc add --start only once the human says yes. To park work for later, file it in Skelcrew's backlog with sc add. Create an issue in the tracker only when the human explicitly asks for one, such as "file an issue" or "add it to GitHub".

For a long body, give the title and body on stdin instead, which needs no shell quoting: sc add <repo> --start with a heredoc, its first line the title and the rest the body.

It takes the title and body on stdin too. sc start APP-104 starts it, and sc rm APP-104 deletes it while it hasn't started.
